## Overview

This project was completed as part of my Cloud Computing studies at the University of Otago.

The project involved using Terraform to provision and configure cloud infrastructure on Amazon Web Services (AWS), applying infrastructure-as-code principles to automate resource deployment and management.

## Technologies Used

- **Terraform** — Infrastructure provisioning and configuration
- **Amazon EC2** — Cloud-based virtual machines
- **Amazon S3** — Object storage
- **AWS** — Cloud infrastructure and services

## Project Details

The project explored how cloud infrastructure can be defined, deployed, and managed using Terraform rather than manually configuring resources through the AWS Management Console.

Key areas included:

- Provisioning AWS resources using Terraform configuration files.
- Configuring cloud-based compute and storage resources.
- Understanding the relationship between cloud infrastructure, networking, and storage.
- Managing infrastructure using version-controlled configuration.
